## Installing Kex

Kex projects are managed with Tey. Create an application, then build and run it from the project directory.

```shell
tey new hello
cd hello
tey run
```

> [!TIP]
> Type `/` anywhere in a chapter to insert code, tabs, or a callout like this one.
